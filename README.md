# TypeScript Problem Solving and Blog Assignment

## Assignment Overview
In this assignment, I solved 8 basic TypeScript problems to practice the main topics of TypeScript. In my code, I worked with optional parameters, union types, type narrowing, readonly tuples, generics, interfaces, classes with access modifiers, and async functions using Promises.

Here is a short list of the 8 problems I solved:
1. **`multiplyValue`**: Multiplies a number by an optional number, or multiplies by 2 if the second number is not given.
2. **`processInput`**: Checks if the input is a string, number, or boolean using `typeof` and returns the right result.
3. **`formatCoordinate`**: Takes location data using a `readonly` tuple and returns a formatted string.
4. **`concatenateArrays`**: Joins multiple arrays of the same type together using Generics (`<T>`).
5. **`getPopularCourses`**: Filters a list of courses using an `interface` to find published courses with enough students.
6. **`pluckValues`**: Gets specific property values from an array of objects using Generics and `keyof`.
7. **`Employee` & `Manager`**: Uses TypeScript classes, inheritance, and `private` and `protected` properties.
8. **`validateAgeAsync`**: Checks user age using an `async` function and returns a `Promise`.
